    Frequently Asked Questions

    Is my API key secure?

    Yes. All keys are encrypted using AWS KMS-managed keys before storing in Supabase vault storage. Withdrawal functions must be disabled on the exchange keys.

    How does Paper Trading work?

    Paper Trading simulates live market trades against real-time orderbooks with zero capital risk, supporting stop loss (SL) and take profit (TP) executions.
